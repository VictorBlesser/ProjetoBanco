# ProjetoBanco

Sistema simples de banco desenvolvido em Java para praticar lógica de programação, estruturas de decisão e repetição.

Funcionalidades

- Consultar saldo
- Realizar depósito
- Realizar saque
- Encerrar sistema

Tecnologias utilizadas

- Java
- Scanner
- Estruturas condicionais ("if / else")
- Estrutura de repetição ("do while")

Objetivo do projeto

Este projeto foi criado com foco em aprendizado e prática de programação orientada à lógica, simulando operações básicas de um sistema bancário.
